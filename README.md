# 青音 Android 0.8.0-rc8

本工程以用户提供的 本机私有目录中的 `base.apk` 为基线。原包版本 `0.8.0-rc1` / code 80，SHA256：
`3D14295CC6F21A1709DA324AEFB122BB0FE077B918EE0B52EE430F0BCA186DCE`。

原包保留副本位于 baseline/Qingyin-0.8.0-rc1-original.apk，原本地 APK 未改动。

## 保留原包内容

- 43 个原有非生成顶层类与 15 个 Manifest 组件均保留。
- 黑胶唱片、播放旋转与暂停、封面取色、模式快捷按钮、酷狗评论数量、评论和楼层回复入口。
- 歌手/专辑/个人资料/外观、真实音频格式、锁屏歌词等既有功能。
- Node runner 与 3 个原生库逐字节来自用户原包，包含评论和回复的新接口，不替换成旧版运行时。
- 使用同一签名，可覆盖原包安装。签名密钥保留在开发机用户目录的 `%USERPROFILE%\.android\debug.keystore`，未放进备份压缩包。

## 合入功能与界面

- 下一首播放、加入队尾、移除待播、清空待播。队列操作保持当前音频和暂停状态；指定下一首优先于单曲循环和随机模式。
- 保留并验证失败自动跳过、连续全失败停止、主动暂停与旧请求失效保护。
- 日推默认保留接口原顺序，刷新与来源说明放在“更多”菜单中。主页封面缓存按账号、日期和请求世代隔离。
- 资料库统一分组与图标、细分隔线；歌曲操作使用带封面的明暗主题底部面板；图标视觉尺寸与触控范围独立，保留黑胶布局。
- rc3：歌曲操作面板和播放队列改为透明毛玻璃，模糊实际页面内容，加入细描边与柔和高光；根据底图明暗调整文字和按钮颜色。队列内二级菜单也支持叠层玻璃。
- rc4：移除推荐页顶部的来源、数量、获取时间及刷新栏；主页“猜你喜欢”每次点击实时请求当前酷狗账号的 personal FM 推荐，成功后直接播放，不再打开二级列表页。请求失败保留当前播放，重复点击、离开首页及更新的播放操作有过期响应保护。猜你喜欢封面也限制为当日有效。
- rc5：猜你喜欢获取成功并开始播放后，自动打开完整播放界面。播放页进度下方改为简短的当前音质名称，确认无损时显示“无损音质”，未验证时显示“音质待确认”；参数详情仍可在音质设置中查看。
- rc6：播放页右上歌曲菜单改为白色圆角面板，带封面、歌曲信息、收藏/下载/分享/一起听快捷入口，以及歌手、专辑、当前音质、音效、播放器样式、红心动效、播放模式和定时关闭。每项接入实际界面或操作。
- rc6：播放列表保留透明毛玻璃背景，改为“当前播放 + 数量”、模式胶囊、紧凑的歌曲/歌手文字行、来源查看与单项移除。长按仍可指定下一首；清空待播保留当前歌曲。
- rc6：背景按封面面积占比提取主色，保留黑白/灰色封面的中性色，切歌平滑过渡。播放器样式支持黑胶/经典封面；收藏动效支持关闭/轻弹/爱心绽放，设置保存在本机。
- rc7：浅色封面有足够彩色区域时提取代表色系，播放背景改为深色渐变、唱片背后柔光与底部压暗，减少平灰感；纯黑白封面仍保留中性色。切歌渐变过渡，封面缺失时回退至默认背景。播放、暂停、切歌按钮改为圆角轮廓，循环和列表图标统一圆端线条。
- rc8：主页和播放页渐变延伸到透明状态栏，页面标题按真实状态栏/刘海 Insets 避让。玻璃队列改为独立 ListView，拖动和惯性滚动时冻结背景捕获，空闲后恢复；CPU 模糊改为线性滑动窗口，缓存行文字、裁切路径和绘制对象。
- rc8：黑胶移除软件绘制与 40ms 定时限制，改为 VSYNC 和真实时间驱动，缓存静态槽纹/阴影与几何；失焦、暂停、隐藏时停止调度。进度与歌词位置使用轻量更新，未变化的元数据不再重复设置。
- rc8：各页面滚动、触摸和可见动画会请求当前分辨率支持的最高刷新模式；空闲/后台释放请求，尊重系统省电模式。实际帧率仍取决于设备、系统策略和负载。

“一起听”当前为歌曲邀请分享，尚无远程房间或进度同步后台。下载仅使用当前账号接口提供的音源，试听片段须单独确认；交给系统 DownloadManager 保存至应用音乐目录，完成后并入“已下载”。未添加 VIP 权益标记或广告。

日推依然使用青音内独立的酷狗概念版账号会话，不保证与标准版酷狗或其他设备逐首相同。失败不以公共歌单、热门或搜索结果替代。

## 构建与验证

执行 `./build-debug.ps1`。构建需配置 `JAVA_HOME`、`ANDROID_SDK_ROOT` 和 Gradle 8.7（`GRADLE_HOME` 或 PATH）；AGP 8.5.2、SDK 34、Java 11、minSdk 26，ARM64。

这是基于 APK 还原并整合的可维护工程，不声称是未丢失的原始源码。原 C++ 源码不在包内，按原样打包已有原生库。

已验证：

- Gradle assembleDebug 成功，版本 0.8.0-rc8/code87，签名与原包一致。
- 800 组队列随机排列、5760 组失败恢复、320 组队列编辑恢复检查通过。
- Android 14 模拟器覆盖升级和冷启动通过。
- 实际播放服务的 8 个静音夹具通过：队列编辑/单曲循环指定下一首，混合失败后恢复、全失败停止、延时切歌暂停、解析中暂停、过期请求、随机恢复、顺序末尾停止。
- 实际日推返回 30 首；歌曲操作面板、黑胶、评论入口及评论列表已检查。未发布任何测试评论或回复。
- rc3 在 Android 14 模拟器覆盖升级、冷启动通过；检查浅色日推歌曲菜单、黑胶页队列和嵌套队列菜单的玻璃效果，以及关闭二级菜单和队列后的界面恢复。此前队列与失败恢复检查在 rc2 完成，rc3 未改动播放逻辑。
- rc4 覆盖升级、冷启动通过；检查每日推荐无顶部说明/刷新栏。实际点击猜你喜欢（含快速重复点击）后仍停留主页，实时返回的 5 首推荐进入队列并播放；获取时切换至新发现后未启动延迟播放。请求失败分支与账号/页面保护经过代码审查，未人为中断网络或退出账号。
- rc5 覆盖升级、冷启动通过；实际点击猜你喜欢后自动进入黑胶完整播放页，显示新推荐并播放，服务队列为 5 首。返回主页正常，不会重复跳转。

- rc6 在 Android 14 模拟器检查白色菜单的收藏/下载/分享/邀请/音质/音效/歌手/专辑八个入口；播放器样式与红心动效保存检查通过，检查后恢复原选项。玻璃队列、来源弹窗、封面取色和覆盖升级已检查。未发送分享消息，也未执行实际曲目下载；下载流程经过代码审查，仍需实体手机验证系统下载服务及账号音源权限。
